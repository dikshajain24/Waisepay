# Waise Pay – AI-Driven Budgeting App

**Waise Pay** is a mobile budgeting application designed to help users manage their leisure spending and reduce impulsive purchases using AI-powered recommendations and gamified financial tools.

## 🧠 Problem Statement
In today's fast-paced financial landscape, many individuals — especially working professionals and international students — struggle with impulsive spending on non-essential activities. Existing tools lack personalization and engagement, leading to inconsistent budgeting behaviors.

## 🎯 Objective
To design a user-centered, AI-driven mobile app that helps individuals:
- Gain awareness of their spending habits
- Receive personalized, categorized weekly budgets
- Make informed decisions using real-time forecasting
- Curb impulsive spending with gamified financial insights

## 🔍 Key Features
- **Predictive Analytics**: Weekly budgets tailored to user history and income
- **Real-Time Expense Impact**: Forecast how a purchase will affect your budget
- **Gamification**: Visual cues and nudges to encourage thoughtful spending
- **AI Chat Assistant**: Provides budgeting tips and answers spending-related queries
- **Tablet Compatibility**: Designed for both mobile and tablet use

## 🧪 User Research & Testing
- Conducted interviews with working professionals and international students
- Found major pain points: lack of personalized budgeting, tracking fatigue, and impulse control
- Usability testing revealed manual input frustrations and device preferences
- Iterative improvements made to input methods and screen compatibility

## 🚫 Limitations
- AI features were not fully testable due to lack of real data integration
- Prototype tested with hypothetical data and limited sample size

## 🚀 Future Work
- Integrate real financial data securely
- Expand personalization to cultural and regional financial habits
- Scale features with robust AI model evaluation
